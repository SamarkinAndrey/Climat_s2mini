# Прошивка для ESP32-S2 mini — CO2 / Температура / Влажность монитор

Файл прошивки: **`src/firmware_s2mini.cpp`** (самодостаточный, не зависит от остальных файлов проекта).

## Возможности
1. **Датчики**: DHT22 (температура + влажность) через библиотеку DHTNEW, MH-Z19B (CO2) через SoftwareSerial + библиотеку MH-Z19.
2. **Сохранение каждые 10 минут** в CSV-файлы на LittleFS: `/logs/YYYY-MM-DD.csv` (ротация — хранится 20 последних файлов).
3. **Калибровка MH-Z19** из веб-интерфейса: Cal Zero (400 ppm), Cal Span (2000 ppm), включение/выключение автокалибровки ABC (сохраняется в NVS).
4. **Сеть**: режим точки доступа `CO2Monitor` (пароль `12345678`, http://192.168.4.1, есть DNS-capture) + подключение к домашней Wi-Fi из веб-интерфейса (AP остаётся как резерв). Синхронизация времени по NTP.
5. **Веб-интерфейс**: вкладки «Реальное время» (карточки + live-график, обновление 5 с), «Графики», «Wi-Fi», «Калибровка MH-Z19», «Данные» (таблица, список файлов, очистка логов, экспорт CSV).
6. **Графики**: Chart.js (CO₂, температура, влажность) за 12 ч / 2 сут / 5 сут / максимум.

## Подключение (LOLIN ESP32-S2 mini)
| Датчик | Пин датчика | GPIO ESP32 |
|---|---|---|
| DHT22 | DATA | GPIO 4 (+ подтяжка 4.7–10 кОм к 3.3V) |
| DHT22 | VCC / GND | 3V3 / GND |
| MH-Z19 | RX | GPIO 16 (TX ESP32) |
| MH-Z19 | TX | GPIO 17 (RX ESP32) |
| MH-Z19 | Vin | 5V (VBUS), GND → GND |

## Сборка и прошивка
```bash
pio run -e lolin_s2_mini -t upload      # сборка и прошивка (проверено: SUCCESS, Flash ~65%, RAM ~16%)
pio device monitor                       # лог (115200)
```
Проверено: проект собирается без ошибок (Flash ~65%, RAM ~16%).

## Первый запуск
1. Подключитесь к точке доступа **CO2Monitor** и откройте http://192.168.4.1
2. На вкладке «Wi-Fi» введите SSID/пароль домашней сети → устройство перезагрузится в режим STA+AP.
3. Прогрев MH-Z19 — 48 ч; первая ручная калибровка Zero — на свежем воздухе.

API: `/api/current`, `/api/history?points=N`, `/api/files`, `/api/export` (CSV),
`/api/wifi/save|clear`, `/api/calibrate?type=zero|span|abc_on|abc_off`, `/api/sensor`, `/api/logs/clear`.
